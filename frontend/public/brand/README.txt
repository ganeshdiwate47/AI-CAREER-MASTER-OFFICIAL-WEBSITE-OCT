DROP THE APPROVED FINAL LOGO HERE
==================================
Place the file as:  logo.png   (square or horizontal, transparent PNG preferred,
minimum 240x240 px; SVG also works if named logo.svg and referenced in
src/data/site.js as IMAGES.logo = "/brand/logo.svg")

It replaces the built-in placeholder mark in the header and footer
automatically. The favicon (public/favicon.svg) can also be swapped the
same way — replace favicon.svg with the exported mark of the final logo.
